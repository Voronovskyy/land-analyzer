# Посібник користувача

## Система аналізу земельних ділянок «Land Plot Analyzer»

Система доступна у двох варіантах:

| Варіант | Як користуватись | Кому підходить |
|---------|------------------|----------------|
| **Веб-версія** | Браузер, нічого встановлювати не треба | Більшість користувачів |
| **Desktop-версія** | JavaFX-застосунок, запуск через Maven | Локальна робота, інтерактивна 3D-модель |

---

# ЧАСТИНА I. ВЕБ-ВЕРСІЯ

## 1. Початок роботи

Відкрийте сайт у будь-якому браузері — реєстрація не потрібна.

> **Перший запит може тривати до 30 секунд.** Сервер переходить у режим сну при
> відсутності активності; перше звернення його «будить».

Для AI-аналізу у звіті знадобиться **пароль доступу** — його видає адміністратор
системи. Решта функцій працює без пароля.

## 2. Пошук ділянки

Поле пошуку підтримує три формати:

| Формат | Приклад |
|--------|---------|
| **Адреса** | `Львів, вул. Коновальця 5` |
| **Кадастровий номер** | `4610136900:01:001:0001` |
| **Координати меж** | `49.7792,24.0452; 49.7794,24.0454; 49.7793,24.0458` |

Для координат потрібно **щонайменше 3 точки**, розділені крапкою з комою.

Після пошуку з'являються карта з межами ділянки та панель результатів: площа,
висота, оціночна вартість у гривні та доларі, курс USD.

> **Про придатність.** Коефіцієнт придатності свідомо **не показується одразу
> після пошуку** — на цьому етапі відомий лише рельєф, без інфраструктури та
> клімату, і такий відсоток вводив би в оману. Повний розрахунок за шістьма
> чинниками виконується під час генерації звіту.

## 3. Карта

На карті показано межі ділянки та спливаюча підказка з площею, периметром,
висотою і вартістю. Доступні шари перемикаються у правому верхньому куті.

## 4. 3D-модель

Кнопка **«3D Модель ділянки»** відкриває ізометричний вигляд.
Обертання — перетягування миші по горизонталі. Внизу показані ширина, довжина,
периметр, площа та висота.

## 5. PDF-звіт

1. У панелі **«Генерація PDF-звіту»** оберіть потрібні картографічні шари
   (за замовчуванням — Схема, Супутник, Рельєф). Значок **i** біля кожного шару
   пояснює, що він показує і який аналіз додає у звіт.
2. За потреби увімкніть **«Аналіз Claude AI»** — знадобиться пароль доступу.
3. Натисніть **«Завантажити PDF-звіт»**.

Під час генерації показується прогрес-бар зі стадіями. Процес триває
**30–90 секунд** (довше з увімкненим AI). Готовий PDF завантажується браузером
автоматично.

# ЧАСТИНА II. DESKTOP-ВЕРСІЯ

## 6. Підготовка до роботи

1. **Інтернет-з'єднання** — активне (тайли карт, запити до API).
2. **API-ключ Claude** — змінна середовища `ANTHROPIC_API_KEY`. Без неї AI-аналіз
   у звіті буде замінено заглушкою; решта функцій працює.
3. **Шрифт** — параметр `pdf.font.path` у `application.properties`. Зазвичай
   змінювати не потрібно: шрифт із кирилицею вбудований у застосунок, а цей
   шлях використовується лише як запасний.

**Запуск:**
```
mvn javafx:run
```

> **Windows:** якщо карти не завантажуються і виглядають суцільно сірими,
> запустіть із прапорцем `-Djavax.net.ssl.trustStoreType=Windows-ROOT` —
> це проблема сертифікатів Java, а не самої карти.

## 7. Інтерфейс

- **Панель управління (зверху)** — поле введення, кнопки «Пошук», «3D», «Звіт».
- **Карта (основна область)** — інтерактивний Leaflet із межами ділянки.
- **Рядок статусу** — поточна операція.

## 8. Пошук ділянки

Формати введення ті самі, що й у веб-версії (див. §2).

Після знаходження карта центрується на ділянці. Вартість оновлюється двічі:
спершу базова за НГО, потім ринкова за даними DOM.RIA.

## 9. Шари карти

| Шар | Що показує |
|-----|------------|
| Схема (OSM) | Вулиці, будівлі, інфраструктура |
| Топографічний | Рельєф із горизонталями |
| DEM | Цифрова модель висот |
| NDVI | Стан рослинності (зелений = активна вегетація) |
| Супутник | Знімок високої роздільності |
| Hillshade | Тіньовий рельєф, схили |

## 10. 3D-модель

Кнопка **«3D»** відкриває окреме вікно з ізометричним wireframe-видом.
Обертання — перетягування миші. Панель показує геометричні характеристики.

## 11. Генерація PDF-звіту

1. Натисніть **«Звіт»** — відкриється діалог вибору шарів.
2. Оберіть шари та за потреби чекбокс «Генерувати AI аналіз».
3. Натисніть **OK** — система перейде в автоматичний режим.

Орієнтовний час: збір даних ~10–15 с, знімки карт ~15–20 с, AI ~30–60 с.

**Не закривайте вікно під час процесу.** Готовий PDF відкривається автоматично
і зберігається у папці `Reports/`.

# ЧАСТИНА III. СПІЛЬНЕ

## 12. Структура звіту

| Сторінка | Вміст |
|----------|-------|
| 1 | Обкладинка: координати, площа, висота, вартість, коефіцієнт придатності, 3D-модель |
| 2 | Кліматичний паспорт: метеопоказники, графік погоди, інфраструктура, адреса, методологія розрахунку КП, транспортна доступність |
| далі | По сторінці на кожен обраний шар: карта, експертний висновок AI, тематична таблиця |
| остання | Геодезичний додаток: координати меж у WGS 84 |

Кількість сторінок залежить від кількості обраних шарів.

## 13. Як читати коефіцієнт придатності

КП — зважена оцінка за шістьма чинниками: рельєф (15 %), транспортна
доступність (20 %), електромережі (15 %), водні ресурси (10 %), екологічні
ризики (20 %), клімат (20 %). Якщо якісь дані недоступні, ваги пропорційно
перерозподіляються між наявними — у таблиці методології такі рядки позначені
«н/д».

| Значення | Трактування |
|----------|-------------|
| ≥ 90 % | Висока придатність |
| 65–89 % | Середня придатність |
| < 65 % | Знижена придатність |

## 14. Вихідні файли

- **PDF-звіт:** `Reports/Zvit_<Назва>_<YYYY-MM-DD_HH-mm-ss>.pdf`
- **Тимчасові PNG** у `Reports/temp/` — видаляються автоматично після збірки.

## 15. Усунення несправностей

| Проблема | Причина | Рішення |
|----------|---------|---------|
| Сайт довго не відповідає на перший запит | Сервер «спав» | Зачекайте ~30 с |
| «Ділянку не знайдено» | Адреси немає в Nominatim | Уточніть адресу або введіть координати |
| Помилка кадастрового пошуку | Номера немає у локальній базі | Введіть адресу або координати вручну |
| «Невірний пароль. AI-аналіз недоступний» | Хибний пароль доступу | Уточніть пароль в адміністратора |
| У звіті замість аналізу «API ключ Claude не налаштовано» | `ANTHROPIC_API_KEY` не встановлено | Встановіть змінну середовища (локально) або в налаштуваннях хостингу |
| «Помилка генерації звіту. Спробуйте ще раз» | Тайм-аут або збій зовнішнього API | Повторіть; за потреби зменште кількість шарів |
| Карта Hillshade виглядає віддаленою | Для цього регіону немає детальніших даних рельєфу | Це очікувано — система автоматично знижує зум до рівня з реальними даними |
| Ціна показує лише НГО | DOM.RIA недоступний | Тимчасово; оцінка за НГО коректна |
| Таблиця висот «н/д» | Elevation API не відповів 5 разів | Перевірте з'єднання; використано значення за замовчуванням |
| Квадрати замість тексту у PDF | Не знайдено шрифт із кирилицею | Перевірте `pdf.font.path` (desktop) |
| Карти суцільно сірі (desktop) | Проблема сертифікатів Java | Запустіть із `-Djavax.net.ssl.trustStoreType=Windows-ROOT` |
