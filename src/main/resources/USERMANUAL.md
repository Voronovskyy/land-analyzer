# Посібник користувача

## Система аналізу земельних ділянок «Land Plot Analyzer»

---

## 1. Підготовка до роботи

Перед першим запуском переконайтеся:

1. **Інтернет-з'єднання** — активне (завантаження картографічних тайлів, запити до API).
2. **API-ключ Claude** — змінна середовища `ANTHROPIC_API_KEY` встановлена. Без неї AI-аналіз у звіті буде замінено заглушкою; решта функцій працюють без ключа.
3. **Шрифт** — у `application.properties` параметр `pdf.font.path` вказує на TTF-файл із кирилицею (напр. `C:/Windows/Fonts/arial.ttf`). Без нього замість тексту в PDF будуть «квадрати».

**Запуск:**
```
mvn javafx:run
```

---

## 2. Інтерфейс

Головне вікно складається з двох зон:

- **Панель управління (зверху)** — поле введення, кнопки «Пошук», «3D», «Звіт».
- **Карта (основна область)** — інтерактивний Leaflet; показує межі ділянки, попап із ціною та висотою.

У правому нижньому куті карти — рядок статусу поточної операції.

---

## 3. Пошук ділянки

Поле підтримує три формати введення:

| Формат | Приклад | Що відбувається |
|--------|---------|-----------------|
| **Адреса** | `Львів, вул. Коновальця 5` | Geocoding через Nominatim |
| **Кадастровий номер** | `4610136300:05:015:0012` | Пошук у локальній базі ДЗК |
| **Ручні координати** | `49.8401,24.0297; 49.8405,24.0302; 49.8398,24.0310` | Полігон з введених точок (мін. 3) |

Після знаходження ділянки карта центрується, показує межі та попап.
Вартість оновлюється двічі: спочатку базова НГО, потім ринкова (DOM.RIA).

---

## 4. Перегляд карти

Перемикач шарів у правому верхньому куті карти:

| Шар | Що показує |
|-----|------------|
| Схема (OSM) | Вулиці, будівлі, інфраструктура |
| Топографічний | Рельєф із горизонталями |
| DEM | Цифрова модель висот (кольорова шкала) |
| NDVI | Стан рослинності (зелений = гарний покрив) |
| Супутник | Знімок Esri/Google |
| Hillshade | Карта схилів і тіней |

---

## 5. 3D-модель ділянки

Кнопка **«3D»** відкриває окреме вікно з ізометричним wireframe-видом.
Обертання — перетягування миші по горизонталі.
Панель праворуч показує ширину, довжину, периметр, площу та висоту.

---

## 6. Генерація PDF-звіту

1. Натисніть **«Звіт»** — відкриється діалог вибору шарів.
2. Оберіть потрібні шари (за замовчуванням — усі) та чекбокс «Генерувати AI аналіз».
3. Натисніть **OK** — система перейде в автоматичний режим.

**Що відбувається під час генерації:**
- Збір кліматичних даних, інфраструктури, POI, кутових висот (~10–15 сек)
- Послідовне перемикання шарів карти та знімки (~15–20 сек)
- Виклик Claude AI для кожного вибраного шару (~30–60 сек при AI enabled)
- Збірка та відкриття PDF

Не закривайте вікно під час процесу. Прогрес відображається у рядку статусу.

Готовий PDF автоматично відкривається та зберігається у папці `Reports/`.

---

## 7. Вихідні файли

- **PDF-звіт:** `Reports/Zvit_<Назва>_<YYYY-MM-DD_HH-mm>.pdf`
- **Тимчасові PNG-знімки** у `Reports/temp/` — видаляються автоматично після збірки PDF.

---

## 8. Усунення несправностей

| Проблема | Причина | Рішення |
|----------|---------|---------|
| Карта не завантажується | Немає інтернету або Firewall блокує OSM | Перевірте з'єднання; додайте виключення |
| AI-аналіз: «API ключ не налаштовано» | `ANTHROPIC_API_KEY` не встановлено | Встановіть змінну середовища перед запуском |
| Квадрати замість тексту у PDF | Шрифт не знайдено | Перевірте `pdf.font.path` у `application.properties` |
| Ціна показує лише НГО | DOM.RIA API недоступний | Тимчасово; ціна НГО коректна |
| Таблиця висот пуста або «н/д» | Elevation API не відповів 5 разів | Перевірте інтернет; значення замінено дефолтним |
| Звіт без AI-аналізу | AI disabled у діалозі або ключ відсутній | Встановіть ключ або увімкніть чекбокс у діалозі |
| Помилка кадастрового пошуку | Номер відсутній у `cadastre_data.json` | Введіть адресу або ручні координати |
