**Виконавець:** PhD-аспірант кафедри комп'ютерних наук
**Об'єкт розробки:** Програмний комплекс «Land Plot Analyzer v2.0»

## 1. Технологічний стек (Infrastructure & Tools)

Система реалізована на платформі **Java 21**, що забезпечує високу продуктивність та кросплатформність.

* **GUI Фреймворк:** JavaFX 21. Використовується для створення сучасного багатопотокового інтерфейсу.
* **Web-інтеграція:** WebView (на базі WebKit). Дозволяє вбудовувати інтерактивні карти безпосередньо в десктопний додаток.
* **Управління залежностями:** Maven (або Gradle).
* **Логування:** SLF4J + Logback для моніторингу роботи ШІ та помилок мережі.

## 2. Джерела даних (Data Acquisition)

Система працює за принципом агрегатора, збираючи дані з різних незалежних джерел у реальному часі:

1. **Геокодування (Адреса -> Координати):** API **Nominatim (OpenStreetMap)**. Дозволяє безкоштовно отримувати GPS-координати за текстовим запитом.
2. **Кадастрові дані:** Імітаційний сервер (`CadastreApiService`), що працює з форматом **GeoJSON**. У реальних умовах це інтеграція з API Державного земельного кадастру (ДЗК).
3. **Висотні дані (DEM):** API **Open-Elevation**. Надає цифрові моделі рельєфу (Digital Elevation Model) на основі супутникових даних SRTM.
4. **Картографічні шари:** * *Standard:* OpenStreetMap.
* *Satellite:* Esri World Imagery.
* *Topo/Terrain:* Esri World Topo.
* *Vegetation:* NDVI (Sentinel-2 Cloudless).


5. **Фінансові дані:** API **ПриватБанку** та **НБУ** для отримання актуального курсу валют.
6. **Інтелектуальна аналітика:** **Google Gemini 2.0 Flash API**.

## 3. Математичний апарат та бібліотеки обробки (Data Processing)

Ключова наукова новизна полягає в методах обробки зібраних даних:

* **Геопросторова обробка:** Використовується бібліотека **JTS (JTS Topology Suite)** — галузевий стандарт для векторних операцій.
* *Обчислення площі:* Реалізовано через формулу Гаусса (Shoelace formula) у класі `GeoAnalysisUtil`, з урахуванням викривлення Землі та проєкції на косинус широти.


* **Геометричне моделювання:** Власна реалізація `LandParcel3dVisualizer`. Це математичний двигун, що перетворює 2D-координати меж та 1D-дані висоти у 3D-модель (Axonometric Projection) за допомогою тригонометричних перетворень на JavaFX Canvas.
* **Клієнт-серверна логіка:** Використовується `HttpClient` для асинхронних запитів, що не блокують інтерфейс користувача.

## 4. Інтеграція штучного інтелекту (AI Integration)

Система не просто відображає дані, а інтерпретує їх за допомогою **LLM (Large Language Model)**.

* **Метод:** Ролеве моделювання (Prompt Engineering). Для кожного розділу звіту створюється окремий контекст: "Ти еколог", "Ти гідролог", "Ти аналітик інвестицій".
* **Обробка:** Дані про координати передаються в модель, яка на основі внутрішніх знань про світову картографію та топологію генерує експертний висновок.
* **Стійкість:** Реалізовано систему логування запитів/відповідей для PhD моніторингу (контроль часу затримки та релевантності відповідей).

## 5. Ланцюжок формування експертного звіту (Workflow)

Процес повністю автоматизований через клас `ReportCoordinator`:

1. **Capture Stage:** Програма послідовно перемикає шари в WebView (Leaflet.js). Використовується `CountDownLatch` для синхронізації: ми чекаємо, поки тайли карти повністю завантажаться, перш ніж робити знімок екрана.
2. **3D Snapshot:** Паралельно рендериться 3D-модель ділянки.
3. **AI Analysis:** Одночасно відправляється 5 паралельних запитів до Gemini для аналізу інфраструктури, рельєфу, води, вегетації та ретроспективи забудови.
4. **Assembly Stage:** Бібліотека **OpenPDF** збирає всі елементи (текст, карти, ШІ-висновки, таблиці координат) в один документ.
5. **Finalization:** Виконується автоматична очистка тимчасових файлів (`File.delete()`) та виклик системного переглядача для демонстрації результату.

## 6. Висновки про наукову новизну

Розроблена система демонструє:

* Ефективне поєднання **векторних геоданих** та **генеративного ШІ**.
* Автоматизацію процесу створення **комплексних землевпорядних звітів**, що зазвичай вимагає роботи декількох фахівців.
* Метод динамічної візуалізації рельєфу на основі відкритих DEM-даних.

## 🔬 Наукова новизна та практична значущість проєкту

У межах наукового дослідження було отримано наступні результати, що мають елементи наукової новизни:

### 1. Методологія інтелектуальної мультимодальної оцінки

Вперше запропоновано підхід до комплексної оцінки земельних ділянок, який поєднує **геопросторові метрики** (площа, висота, ухил) із **семантичним аналізом** великих мовних моделей (LLM). Це дозволяє автоматизувати формування експертних висновків, які раніше потребували залучення фахівців з урбаністики, гідрології та екології одночасно.

### 2. Модель автоматизованої генерації просторових звітів

Розроблено алгоритм синхронізації асинхронних процесів (захоплення растрових даних карти, рендеринг 3D-моделей та API-запити до ШІ), що дозволяє формувати цілісний цифровий документ з високим рівнем достовірності. Впроваджений механізм **`ReportCoordinator`** мінімізує похибки завантаження картографічних даних при автоматичному скріншотуванні за рахунок керованих затримок та подійного керування (Event-driven management).

### 3. Алгоритм динамічної аксонометричної візуалізації рельєфу

Удосконалено метод візуалізації мікрорельєфу земельної ділянки на основі дискретних значень цифрової моделі висот (DEM). На відміну від статичних 2D-карт, запропонована реалізація дозволяє будувати **тривимірну дротяну модель (Wireframe)** у режимі реального часу, що підвищує якість візуального аналізу морфологічних особливостей території для цілей лісотехнічного проектування.

### 4. Гібридна модель розрахунку економіко-екологічної цінності

Розроблено програмну реалізацію оцінки придатності ділянки, яка враховує:

* Динамічні економічні показники (курс валют через API банківського сектору).
* Екологічні індекси (дистанційне зондування через NDVI).
* Топографічні обмеження (аналіз ухилів через геоморфологічний модуль).
