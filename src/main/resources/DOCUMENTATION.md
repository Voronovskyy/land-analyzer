# 🌍 Land Plot Analyzer v1.0
## Технічна документація інтелектуальної ГІС-системи

Ця документація описує архітектуру, модулі та технологічний стек системи аналізу земельних ділянок, розробленої в межах науково-дослідної роботи.

---

## 📂 1. Структура пакетів (Package Structure)
Всі компоненти системи розташовані в базовому пакеті: `ua.edu.university`.

| Пакет | Клас | Роль у системі |
| :--- | :--- | :--- |
| **main** | `MainApplication` | Точка входу. Завантажує FXML та ініціалізує вікно JavaFX. |
| **model** | `Coordinate` | **Data Container.** Зберігає Lat/Lon, GeoJSON, висоту, бал придатності та точки меж. |
| **api** | `GeoApiService` | **OSM/Cadastre Client.** Отримує геометрію ділянки за запитом. |
| **api** | `ElevationApiService` | **Terrain Client.** Запитує висоту (DEM) через Open-Elevation API. |
| **api** | `ExchangeRateService` | **Finance Client.** Отримує курс USD від НБУ. |
| **util** | `GeoAnalysisUtil` | **Math Engine.** Розраховує площу (JTS), парсить координати та Suitability. |
| **util** | `MapHtmlBuilder` | **Frontend Generator.** Створює HTML/JS код для WebView (Leaflet). |
| **util** | `PdfReportService` | **Document Engine.** Формує багатосторінковий PDF-звіт. |
| **util** | `ReportCoordinator` | **Process Manager.** Керує асинхронними знімками екрана та шарами. |
| **controller** | `MainController` | **Bridge.** Поєднує логіку сервісів з графічним інтерфейсом користувача. |

## 🛠 2. Детальний опис ключових компонентів

### 🧬 `model/Coordinate.java`
Об'єктна модель, що є "серцем" даних системи.
* **Функціонал:** Зберігає результати аналітики після обробки.
* **Поля:** `averageElevation` (висота), `suitabilityScore` (0.0-1.0), `boundaries` (список кутів).

### 📐 `util/GeoAnalysisUtil.java`
Математичний апарат системи.
* **`calculateAreaFromGeoJson`**: Використовує бібліотеку **JTS** для обчислення площі з урахуванням викривлення земної поверхні.
* **`extractBoundaries`**: Перетворює сирі геодані на перелік технічних координат.
* **`calculateSuitability`**: Експертний алгоритм оцінки лісотехнічної придатності (залежність рельєф/площа).

### 🌍 `util/MapHtmlBuilder.java`
Динамічна генерація картографічного інтерфейсу.
* **Візуалізація:** Використовує **Esri World Topo Map** та **Hillshade** для відображення рельєфу та горизонталей.
* **Інтерактивність:** Формує "Економічний паспорт" у Popup-вікнах на карті.

### 🕒 `util/ReportCoordinator.java`
Керує складним асинхронним процесом генерації звіту.
1. Фіксує **План-схему**.
2. Перемикає шар на **Рельєф**, очікує 5с (завантаження тайлів), робить знімок.
3. Перемикає на **Супутник**, очікує 5с, робить знімок.
4. Ініціює збірку документа в `PdfReportService`.

## 📄 3. Структура PDF-звіту (4 сторінки)
Система автоматично генерує документ з наступним змістом:
1. **Титульна сторінка:** Аналітична таблиця характеристик + Карта-схема.
2. **Геоморфологія:** Карта рельєфу (гіпсометрія) з горизонталями.
3. **Моніторинг:** Актуальний супутниковий знімок високої роздільної здатності.
4. **Технічний додаток:** Повна таблиця координат усіх поворотних точок меж.

## ⚙️ 4. Ресурси та конфігурація
* `src/main/resources/config.properties`: Налаштування кольорів, зуму та API-посилань.
* `src/main/resources/fonts/arial.ttf`: Шрифт для коректного відображення кирилиці в PDF.
* `Reports/`: Директорія для вихідних документів та тимчасових кеш-файлів.

## 🚀 5. Технологічна новизна
* **ГІС-інтеграція:** Гібридне поєднання векторного (GeoJSON) та растрового аналізу.
* **Асинхронність:** Реалізація через `CompletableFuture` для стабільності UI.
* **DEM-аналіз:** Математична модель оцінки на основі цифрових моделей рельєфу.
